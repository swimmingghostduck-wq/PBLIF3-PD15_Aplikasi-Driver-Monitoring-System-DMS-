# PBLIF3-PD15_Aplikasi-Driver-Monitoring-System-DMS-
Aplikasi untuk memantau kondisi dan perilaku pengemudi  secara real-time guna meningkatkan keselamatan berkendara. Sistem ini dirancang untuk mencari tanda-tanda kelelahan dna perilaku yang berisiko lainnya dengan menggunakan teknologi seperti pengenalan wajah, analisis gerakan mata, dan deteksi perilaku.
